# ⚕🤍Sistema de Gestión de Farmacia: Implementación de Ramas
Este proyecto fue desarrollado para la creacion e identificacion de ramas en git y utilizacion del merge.
Y en el se representa la implementación de un sistema de gestión integral para una farmacia.

## Funcionalidades 
Implementa un sistema integral de gestión que permita manejar todas las operaciones relacionadas con la administración de medicamentos, proveedores, empleados, pacientes, así como la generación de informes relevantes.

## Estructura del repositorio

Este repositorio contienen 7 elementos los cuales son:

1.Main.py 

2.Seis archivos json:

    Compra.json
    Ventas.json
    Medicamentos.json
    Empleados.json
    Proveedores.json
    +Pacientes.json
## Uso
1.  Asegúrate de tener Python 3.x instalado.
